## 🇬🇧 Description (English)

**Nigimi Network Controller** is a high-performance Windows kernel-level network traffic management tool. It allows you to instantly limit speeds, mute internet access for selected applications, and eliminate game ping spikes.

### 🔥 Key Features:
* 🎯 **Gaming Priority:** Mute background apps and downloads in one click for minimum latency in CS2 and other titles.
* ⚡ **Traffic Shaping:** Precise download and upload speed limits for any individual process.
* 🚫 **Instant Network Mute:** Block application traffic instantly without messy Windows Firewall rules.
* 🌐 **Multi-language:** Built-in support for 5 languages (Russian, English, Deutsch, Chinese, Arabic).
* 🚀 **Autostart Manager:** Seamless Windows startup integration via Registry/Task Scheduler.

### 📥 Quick Start:
1. Go to the **[Releases](../../releases)** section on the right.
2. Download the latest `Nigimi_Setup_v2.0.exe`.
3. Install and run as Administrator.
